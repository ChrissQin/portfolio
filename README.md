# Chris Qin — Portfolio

Personal portfolio for Chris Qin, Video Editor & Videographer.

Built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Develop

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run lint
npm run typecheck
npm run build
```

## Customize

- Site constants (email, socials, resume, availability): `lib/constants.ts`
- Project types & helpers: `lib/projects.ts`
- Project data: `data/projects.ts`

Contact details and social links start as `null` placeholders. Do not invent values.
